# Visualization 3 Improvements

- Based on the principle of using a common scale, I changed the chart to a horizontal dumbbell plot, so the viewer can compare 2010 and 2020 percentages on the same axis.
- Based on the principle of making comparisons easy, I connected each race category's 2010 and 2020 points with a line, so the viewer can quickly see whether each percentage increased or decreased.
- Based on the principle of meaningful ordering, I sorted categories by their 2020 percentage, so the viewer can understand current prevalence and compare category rankings.
- Based on the principle of clear labeling, I used percentage axis labels and a simple year legend, so the viewer can read the chart without decoding raw population counts.
- Based on the principle of showing exact values when needed, I added tooltips with race category, census year, percent of population, and population count, so the viewer can answer detailed questions accurately.
